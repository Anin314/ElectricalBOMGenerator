# -BOM-
用于生成标准组件情况下的电气BOM

🖥️ 使用指南
基本工作流
管理基础数据

菜单栏 → “库管理” → “电气元件库管理” → 添加/导入元件。

“库管理” → “组件库管理” → 创建组件，添加电气物料，并可配置IO点。

创建项目

“项目” → “新建项目”，输入项目名称。

在“机架列表”区域右键或使用右侧按钮新建机架。

向机架添加内容

在“可用资源”选项卡中搜索并选中组件或元件，点击“添加选中到当前机架”。

组件会出现在“机架内容”列表，元件则只会显示在下方的“机架电气元件明细”中。

支持数量累加去重。

生成 BOM

点击底部“生成BOM”按钮预览物料清单。

点击“导出Excel”即可生成带物料明细和IO分配表的工作簿。
